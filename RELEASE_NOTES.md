# Roblox Reference Library v0.1.0

A portable local gallery for the original frrazers Roblox reference dataset:
143,865 images across 28,756 games (43,115 icons and 100,750 thumbnails).

Download the application ZIP here and get the **Everything** dataset directly from
its creator: https://tools.frrazers.com/dataset/

Extract both downloads separately, keep the original image names, and run **Start Gallery.cmd**.
The app finds the original dataset or asks for its extracted folder path, then reads it in place.
The application download does not redistribute the images.

The saved game metadata and complete scene-search index are included. No Codex,
Python installation, GPU, account, or paid service is required. After setup, browsing
works offline without repeating collection or image analysis.

- Filter by genre, subgenre, name, and games over a visit count.
- Hover through saved images or show every image in the main grid; up to 480 per page.
- Find similar references by full scene, game type, or both. Scenes come first, colors second.
- Visual similarity always shows the exact matching saved images.

Windows 10/11 x64. Application source is MIT licensed. Game artwork belongs to its
original creators; downloading it does not grant permission to reuse it. See NOTICE.md.
Visual matches are approximate, and game details are a cached snapshot.
